## 2024-05-18 - Styling Conditional Portals and Absolute Button Padding in Scrollable Blocks
**Learning:** When using component-scoped `<style>` tags with conditionally rendered portals or overlays, placing the style block inside the conditionally rendered branch causes the main DOM trigger elements to lose their styling when the portal is closed. Additionally, absolute-positioned buttons placed over scrollable text regions (like `<pre>`) can overlap the text; the scrollable region requires explicit padding to account for the button width to prevent text from sliding underneath and being hidden.
**Action:** Always render `<style>` blocks unconditionally (typically via a React Fragment) when they style elements that persist outside of conditional modal/portal branches. Apply `padding-right` or `padding-bottom` (and a solid background) to scrollable content containers if they host absolute-positioned action buttons like "Copy Code".
