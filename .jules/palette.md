## 2026-10-11 - CodeExport close button accessible name\n**Learning:** In this codebase, interactive standard buttons (such as '×' for close) used within custom modal components often lack `aria-label`s. The `CodeExport` component had an icon-only close button marked only with `×` without an `aria-label`.\n**Action:** When modifying or creating modals, explicitly ensure that icon-only buttons include an accessible name (e.g., `aria-label="Close modal"`).
