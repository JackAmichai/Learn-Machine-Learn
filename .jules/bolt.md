## 2024-11-20 - Asynchronous Tensor Extraction in React useEffect
**Learning:** Calling `dataSync()` on a tensor blocks the main UI thread while waiting for the GPU to return the data. If this happens frequently in a render cycle (like during model training visualization), it causes severe UI jank. However, converting it to asynchronous `.data()` inside a `useEffect` requires careful teardown: `tf.tidy()` cannot wrap asynchronous code, so tensors (`inputTensor`, `predTensor`) must be manually tracked and disposed of using a `try...finally` block to prevent GPU memory leaks. Furthermore, an `isMounted` flag is crucial to prevent state updates on unmounted components while awaiting the GPU.
**Action:** When replacing `dataSync()` with `await data()` in React, always remove `tf.tidy()`, implement manual tensor disposal in a `finally` block, and use an `isMounted` flag to guard async DOM/state updates.
