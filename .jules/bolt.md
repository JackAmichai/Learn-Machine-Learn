## 2024-03-04 - TF.js dataSync() UI Blocking in React useEffect
**Learning:** Calling `dataSync()` inside a React `useEffect` blocks the main UI thread during tensor evaluation, causing jank. `tf.tidy()` automatically disposes tensors created inside unless explicitly returned; assigning to an outer variable without returning causes premature disposal.
**Action:** Replace `dataSync()` with `await data()`. Wrap tensor creation in `tf.tidy()`, explicitly return the final tensor, await its `.data()` outside, use an `isActive` cancellation flag to prevent race conditions during rapid state changes, and manually dispose of the tensor in a `try/finally` block.
