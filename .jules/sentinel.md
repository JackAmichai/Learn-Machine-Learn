## 2024-05-18 - XSS via dangerouslySetInnerHTML\n**Vulnerability:** Found multiple usages of `dangerouslySetInnerHTML` rendering untrusted HTML strings without sanitization in `MathModal.jsx` and `LookingForward.jsx`.\n**Learning:** By directly rendering variables like `data.content` which come from a data file, we expose the application to potential XSS attacks if the content source is ever compromised or user-influenced.\n**Prevention:** Always use a sanitization library like `DOMPurify` to clean HTML content before passing it to `dangerouslySetInnerHTML`.
