## 2023-10-27 - DOMPurify Configuration for Specialized Math Applications
**Vulnerability:** Default DOMPurify sanitization strips essential SVG and MathML elements used in educational visualizations, causing broken rendering when applying standard XSS protections.
**Learning:** In applications rendering complex mathematical formulas or diagrams (like neural-visualizer), `dangerouslySetInnerHTML` is often used to inject rich content containing `<math>`, `<svg>`, and related nested tags. Applying basic `DOMPurify.sanitize(data)` safely prevents XSS but inadvertently breaks the application's core visual functionality by aggressively removing these specialized elements.
**Prevention:** Always evaluate the expected content format before applying sanitization. For math/diagram-heavy apps, utilize DOMPurify's built-in profiles instead of manually whitelisting tags. Use `DOMPurify.sanitize(data, { USE_PROFILES: { html: true, mathMl: true, svg: true } })` to robustly allow standard HTML alongside safe MathML and SVG structures, securing the app without compromising its educational features.
