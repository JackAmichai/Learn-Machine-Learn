## 2026-04-23 - Client-side DoS in FileReader\n**Vulnerability:** Reading user-uploaded files directly into memory with FileReader without checking file size can cause the browser to crash if the file is excessively large.\n**Learning:** The application parsed JSON files using `FileReader.readAsText` directly, leaving it vulnerable to memory exhaustion from malicious users.\n**Prevention:** Always enforce a strict file size limit (e.g., 5MB) on user uploads before calling any `FileReader` methods.\n
