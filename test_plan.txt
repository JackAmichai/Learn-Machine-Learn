> In a Vite application, environment variables prefixed with `VITE_` (e.g., `VITE_HF_TOKEN`) are statically injected into the client-side JavaScript bundle at build time. To prevent developer API keys/tokens from being exposed, remove them from `import.meta.env` and enforce a Bring-Your-Own-Key (BYOK) approach using only `localStorage`.
